# 安全、版权与隐私

## 1. 内容安全

### 电子书

EPUB 可能包含脚本、远程资源、字体和复杂 HTML。必须：

- 禁止脚本。
- iframe sandbox。
- 严格 CSP。
- 不允许 `file://` 任意访问。
- 不允许电子书请求任意远程资源。
- 外链通过受控 opener 打开。

### 网页

- 只允许 HTTP/HTTPS。
- 桌面请求防 SSRF。
- 默认阻止本地、回环、链路本地和云元数据地址。
- 限制重定向次数、下载大小、超时和 MIME。
- Readability 之后再次清理 HTML。

### 文件

- 检查扩展名和真实 MIME。
- 设置大小上限。
- 解析可取消。
- 临时文件退出清理。
- 记录 SHA-256。

## 2. AI 隐私

调用外部模型前必须明确说明：

- 哪些正文将被发送。
- 发送到哪个服务商或用户自定义服务。
- 是否保留日志。
- 是否可以关闭。

默认建议：

- 规则拆分本地完成。
- AI 仅发送必要 blocks。
- 不发送整个文件。
- 对敏感文档提供“永不发送”标记。

## 3. 密钥

禁止：

- 写入前端源码。
- 写入 Tauri 配置。
- 写入 Git。
- 写入普通日志。
- 明文放 SQLite。

个人模式使用操作系统安全存储；商业模式由自有服务端代理。

## 4. 版权

- 仅处理用户拥有或有权访问的内容。
- 不内置盗版书库。
- 不提供 DRM 绕过。
- 不公开分享用户导入的现代书全文。
- 网页保留来源 URL。
- 示例优先使用公版内容或原创内容。
- 导出收藏时提醒用户尊重版权。

## 5. 数据删除

删除来源时提供：

- 删除原始文件。
- 删除解析 blocks。
- 删除 segments。
- 删除 AI cache。
- 是否导出/保留用户笔记。

删除需要事务化，并可生成审计摘要。

## 6. 日志

可记录：

- 文件类型、大小和哈希。
- 解析器版本。
- 错误码。
- 片段数量和覆盖率。
- 调度跳过原因。

默认不可记录：

- 完整正文。
- API Key。
- 用户笔记全文。
- 敏感 URL 参数。

## 7. 最小权限

Tauri capabilities 只开放：

- 核心窗口能力。
- autostart 必要命令。
- notification 必要命令。
- opener 必要 URL/path。

新增插件前先写威胁模型和最小 scope。

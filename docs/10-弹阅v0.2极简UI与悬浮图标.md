# 弹阅 v0.2 极简 UI 与悬浮图标说明

更新时间：2026-08-27

## 1. 设计目标

v0.2 将产品正式命名为 **弹阅**，主界面从偏密集的阅读仪表盘调整为更克制的桌面阅读工具：

- 浅色、留白、低饱和，接近 macOS 原生应用的安静感。
- 主页面只回答“今天读什么、读了多少、下一次什么时候出现”。
- 阅读弹窗是主角，统计与管理退到第二层。
- 悬浮图标作为全天常驻入口，不要求用户反复打开主窗口。
- 所有动画、阴影和玻璃效果都应轻量，不牺牲文字清晰度。

## 2. 主界面信息架构

左侧只保留五个入口：

1. 今日
2. 书架
3. 阅读计划
4. 收藏
5. 设置

今日页由四部分组成：

- 轻量问候与品牌主张：“少而精地读，深而静地思。”
- 今日阅读摘要：分钟、确认读完段数、收藏数。
- 最多三本继续阅读书籍。
- 阅读计划与今日时间线。

不在首页堆放排行榜、复杂图表、等级、积分、社交和大量运营入口。

## 3. 悬浮图标

### 3.1 收起状态

悬浮图标是一个 52px 的透明原生窗口，内部只保留 48px 品牌图标：

- 中心为弹阅开卷标识。
- 不显示含义不明确的进度环或数字角标。
- 浏览器预览模式支持拖拽并记忆位置。
- Tauri 桌面模式由独立 `reading-floating` 窗口承载，置顶、透明、跳过任务栏。

### 3.2 点击行为

点击悬浮图标后：

1. 打开独立 `reading-popup` 微读窗口。
2. 弹窗与图标保持相邻和联动位置。
3. 打开主窗口时隐藏悬浮入口，主窗口收起到托盘后恢复。
4. 用户在设置中关闭悬浮图标时，桌面窗口会被销毁，而不是继续后台显示。

## 4. 展开阅读弹窗

弹窗保留四个明确动作：

| 动作 | 含义 |
|---|---|
| 继续阅读 | 打开连续阅读面板，不自动确认当前片段已读 |
| 读完下一段 | 确认当前片段，并切换到下一段 |
| 稍后提醒 | 延后 30 分钟并关闭弹窗 |
| 今天暂停 | 今天不再自动提醒，次日恢复 |

弹窗默认按预计阅读时长加缓冲自动关闭，仍然只记录“已展示”，不记录“确认读完”。鼠标悬停或键盘焦点进入时可暂停倒计时；收藏保留在连续阅读界面。尺寸默认随正文自适应，也可在设置中限制为紧凑或小窗上限，较长正文在正文区滚动。

## 5. 样式分层

- `src/styles.css`：基础组件、旧页面兼容和响应式底座。
- `src/apple.css`：v0.2 品牌与苹果风视觉覆盖层。

分层的目的，是让本地 AI 可以重构视觉，而不轻易破坏导入、计划、书架、阅读器和设置等既有功能。

## 6. 桌面窗口

| 窗口 | 标签 | 作用 |
|---|---|---|
| 主窗口 | `main` | 书架、计划、设置和连续阅读 |
| 微读弹窗 | `reading-popup` | 定时出现的阅读卡片 |
| 悬浮图标 | `reading-floating` | 全天常驻的轻量入口 |

桌面源码已经提供窗口创建、定位、显示、隐藏和托盘命令；真实 Windows/macOS 行为仍需本机执行 `cargo check`、`npm run tauri:dev` 和焦点测试。

## 7. 验收重点

- 主界面在 1280×800 下无横向溢出。
- 悬浮图标点击区域不小于 44×44px。
- 悬浮图标启停设置即时生效。
- 微读弹窗出现时不抢走当前输入焦点。
- 弹窗关闭后悬浮图标恢复。
- 四个按钮的状态语义准确，不能把“打开连续阅读”误记为“已读”。
- 深色模式、减少动画和字体缩放仍然可用。

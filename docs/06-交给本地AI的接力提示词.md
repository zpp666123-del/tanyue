# 交给本地 AI/Codex 的接力提示词

## A. 总负责人会话提示词

```text
你现在是“弹阅”桌面微阅读项目的软件与产品总负责人。

先完整阅读：
1. README.md
2. PROJECT_STATUS.md
3. AGENTS.md
4. docs/01-产品方案总纲.md
5. docs/02-架构与数据模型.md
6. docs/03-UI与交互规范.md
7. docs/05-开发路线与验收.md

产品目标：
构建 Windows 优先、Local-first 的桌面微阅读工具。弹阅直接解析 TXT/Markdown；复杂书籍、文档或网页由外部 Agent 转换为标准 `.tanyue.json` 包，弹阅复核后通过不抢焦点的桌面浮窗按计划呈现。

绝对约束：
- AI 不得替换原文。
- 每段必须保留来源锚点和内容指纹。
- 正文块不得漏、重、乱序。
- 自动关闭只记已展示，不记确认读完。
- 弹窗必须容易关闭、延后和当天暂停。
- 不内置模型密钥，不默认上传原文，不执行电子书脚本，不绕过 DRM。
- 不把产品做成重型阅读器、书城、知识库、打卡游戏或团队协作平台。

你的工作方式：
1. 先运行 npm run verify，记录当前基线。
2. 检查 Windows/Rust/Tauri 环境。
3. 根据 PROJECT_STATUS.md 选择一个且只有一个当前 Goal。
4. 写明验收标准、不改范围和风险。
5. 先补测试或可重复复现步骤。
6. 实现纵向闭环。
7. 运行全部门禁。
8. 更新 PROJECT_STATUS.md 和相关文档。
9. 不能只汇报“代码写完”；必须给出真实运行、测试和未验证项。

第一 Goal：
在 Windows 真机让 Tauri 桌面版编译运行，修正所有 Rust/API/权限问题，并完成以下测试：
- 主窗口关闭到托盘。
- 托盘操作可用。
- 阅读弹窗右下角出现。
- 用户在 Word 或 VS Code 持续打字时，自动弹窗不抢键盘焦点。
- 用户点击弹窗后按钮可操作。
- 开机启动开关可逆。
- 休眠恢复后不补弹错过提醒。

完成第一 Goal 后不要自行扩范围。先更新状态并提出下一 Goal 建议。
```

## B. SQLite 会话提示词

```text
只负责弹阅的本地持久化重构，不改 UI 视觉和格式解析。

目标：
把 LocalStorage 演示状态迁移到 SQLite，建立 Source → SourceVersion → Block → SegmentRun → Segment 的可追溯结构，同时保留阅读事件、收藏、笔记、计划和设置。

要求：
- 先设计 schema 和迁移。
- 原始文件保存在 app data 文件目录，SQLite 保存元数据和 SHA-256。
- 提供 LocalStorage 一次性导入。
- 迁移失败前保留备份。
- repositories 与 UI 分离。
- 重新拆分不能静默丢笔记和收藏。
- 增加集成测试。
- 更新 PROJECT_STATUS.md。

禁止：
- 同时接 EPUB/PDF。
- 重写界面。
- 引入云端账号。
```

## C. Agent 导入包会话提示词

```text
只负责把用户提供的合法来源转换为弹阅标准包，不改弹阅数据库、调度器和视觉。

目标：
先从安装目录运行 `tanyue-cli schema` 取得当前协议，再解析输入、生成完整原文块和连续片段范围，最后运行 `tanyue-cli validate` 与 `tanyue-cli import`。

输出：
- 符合 Schema 的 `.tanyue.json` 文件。
- 原文 blocks、sourceAnchor、parser/segmenter/rule 版本。
- 每个可阅读字符被且只被一个 segment span 覆盖。
- CLI 的机器可读校验结果和明确失败原因。

禁止直接写 SQLite、覆盖原文、绕过 DRM 或默认上传原文。无需安装专用 Skill 或连接 MCP；只有单次文件转换和 CLI 投递。
```

## D. 复杂格式处理边界

```text
EPUB 保留 CFI 或章节定位，PDF 保留页码与文字范围，DOCX 保留结构块，URL 保留原地址和 DOM/段落定位。扫描件、加密/DRM、空正文、多栏顺序不确定或网页反爬都必须明确失败或提示用户复核，不能伪造 100% 覆盖结果。
```

## E. UI 质检会话提示词

```text
只审计并修正弹阅现有 UI，不改变产品范围。

检查：
- 1366×768、1920×1080、150% 缩放。
- 明暗主题。
- 弹窗按预计阅读时长自适应，固定模式支持 15～90 秒内容。
- 原文与解释层级。
- 键盘和屏幕阅读器。
- 所有关闭、延后、今天暂停入口。
- 不使用营销式打卡文案。
- 焦点可见性和对比度。

必须用真实渲染截图逐页比较，不能只读 CSS 便宣称完成。
```

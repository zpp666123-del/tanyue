## 0. 一句话结论

用户端全程零凭证：点「检查更新」→ 匿名拉取一份静态 JSON → 匿名下载安装包（客户端用内置公钥验签）→ 一键安装并重启。用户不需要登录、不需要 token、不需要申请任何东西。

唯一需要"凭证"的是**发布方**：一份更新签名私钥（`D:\tanyue\keys\`，已生成，绝不进 git/安装包）+ GitHub 仓库写权限（gh CLI 已登录 `zpp666123-del`）。这是"发布的钥匙"，与用户下载无关。

## 2. 机制：为什么用户端零凭证

```
┌───────────── 发布方（你有） ──────────────┐
│ keys/tanyue-updater.key        私钥（已生成，本机保管）│
│ keys/tanyue-updater.key.pub    公钥（已写入 tauri.conf.json）│
│ 每次发版：安装包 + .sig（私钥签名）→ gh release 上传      │
└──────────────┬────────────────────────────┘
               ▼ 匿名 GET（无 token、无 cookie）
┌───────────── 用户端（零凭证） ────────────┐
│ 设置 → 关于与更新 → 检查更新              │
│  GET https://github.com/zpp666123-del/tanyue/ │
│      releases/latest/download/latest.json  │
│  → 下载安装包（公钥验签）→ 重启并安装       │
└──────────────────────────────────────────┘
```

- **endpoints（固定不变）**：`https://github.com/zpp666123-del/tanyue/releases/latest/download/latest.json`。GitHub 的 `releases/latest/download/<资产名>` 永远指向最新 Release，因此客户端配置无需随版本修改。
- **安装包资产名固定为 ASCII 名 `tanyue-setup.exe`**（每次 Release 同名上传），规避中文文件名 URL 编码问题；`latest.json` 内 `url` 也固定。
- 签名链：私钥给安装包签名（`.sig`），客户端内置的公钥验签；伪造包无法通过。
- 检查更新仅为一次匿名 HTTPS GET；无任何密钥、账户信息进入客户端。

## 5. 发版流程（以后每次发新版照做）

```powershell
# 1. 提升版本（package.json / src-tauri/Cargo.toml / tauri.conf.json / src/utils.ts APP_VERSION 同步）
# 2. 构建安装包（含签名产物 .sig）
$env:TAURI_SIGNING_PRIVATE_KEY_PATH = "D:\tanyue\keys\tanyue-updater.key"
npm run release:windows
# 3. 生成清单并发布到 GitHub（稳定资产名 tanyue-setup.exe + latest.json，匿名可下）
npm run publish:update -- --notes "更新说明..." --upload github
# 4. 验证
curl -s https://github.com/zpp666123-del/tanyue/releases/latest/download/latest.json
```

## 7. 风险与回退

| 风险 | 影响 | 缓解/回退 |
|---|---|---|
| GitHub 国内下载慢/超时 | 下载卡顿 | 状态区显示进度与错误 + 重试；未来可加第二 endpoints 回退 |
| 私钥丢失 | 无法发新版签名 | 备份私钥到密码管理器/加密介质；丢失需重新生成并让存量用户重装 |
| 未签名 Authenticode 可能触发 SmartScreen | 安装时提示"仍要运行" | 发布说明如实写明；后续接 `TANYUE_SIGN_CERT_SHA1` |
| 安装器运行中进程占用 | 升级失败 | 官方顺序：downloadAndInstall 完成后立即 relaunch；失败回退手动下载 release 页 |
| 降级攻击（重放旧清单） | 理论上可降到旧版本 | GitHub 通道 https + 公钥验签，重放仅影响版本选择不破坏内容；接受此窗口 |
| 本地端到端用 http://127.0.0.1 桩 | 需要危险开关 | 仅测试构建用 `--config` 覆盖；**tauri.conf.json 保持 `dangerousInsecureTransportHTTP` 关闭** |

## 8. 非目标（退役边界）

- 不做 macOS/Linux 更新通道（本期仅 Windows x64）。
- 不做多版本灰度/AB；不做启动自动检查弹窗；不做"更新失败自动回滚"（失败即提示手动下载）。
- 不做自建更新管理后台；`latest.json` 由脚本自动生成，版本历史归 GitHub Releases 与本地 `release/`、`archive/` 管理。

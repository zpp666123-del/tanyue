# 演示数据来源与校勘说明

## 1. 《道德经》演示数据的用途

工程内置《道德经》完整八十一章，用来验证这条最关键的纵向链路：

```text
完整书籍 → 自然章识别 → 顺序入库 → 定时展示 → 阅读确认 → 重启接续
```

它同时作为自动化验收数据，当前测试会检查：

- 必须恰好包含 81 章。
- 第一章和第八十一章标题正确。
- `sequence` 从 1 到 81 连续。
- 不允许出现空正文。
- 81 章正文指纹不得重复。

## 2. 文本性质

《道德经》原典属于古代公版文本。不同传本、整理本在用字、标点、句读与个别字词上可能不同，因此本工程中的文本只能作为功能演示和测试底本，不能自动等同于经过学术校勘的正式出版底本。

正式商业发布前应当：

1. 明确选择一个可公开使用的底本或自行整理的版本。
2. 由人工对 81 章逐章校勘。
3. 记录底本名称、整理责任人、校勘日期和变更记录。
4. 对 AI 生成的标题、承接语和解释单独审核，并与原文视觉分层。

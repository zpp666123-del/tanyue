# 开源复用与许可证

> 本文是工程决策建议，不替代正式法律意见。商业发布前应由法务复核实际版本和使用方式。

## 1. 推荐直接集成

| 项目 | 用途 | 典型许可 | 结论 |
|---|---|---|---|
| Tauri v2 | 桌面壳、窗口、托盘、安装包 | MIT / Apache-2.0 | 作为整体桌面底座 |
| Tauri Plugins | 开机启动、通知、外部链接 | MIT / Apache-2.0 | 按最小权限接入 |
| foliate-js | EPUB/MOBI/AZW3/FB2 解析和定位 | MIT | 电子书核心适配器候选；固定 commit |
| PDF.js | PDF 渲染与文字提取 | Apache-2.0 | 文字型 PDF 适配器 |
| Mammoth.js | DOCX 转结构化 HTML | BSD-2-Clause | DOCX 适配器 |
| Mozilla Readability | 网页正文提取 | Apache-2.0 | URL 适配器 |
| Stretchly | 提醒、托盘、延后和勿扰交互参考 | BSD-2-Clause | 参考或局部移植，不采用 Electron 整体壳 |
| epub.js | EPUB 专用备用方案 | BSD 风格 | 备用，不与 foliate-js 同时深耦合 |

## 2. 适合后续高级解析

| 项目 | 用途 | 结论 |
|---|---|---|
| Microsoft MarkItDown | Office/PDF 转 Markdown | 可选 sidecar；不让首版依赖 Python |
| Docling | 复杂 PDF、表格和版面 | P1/P2 高级解析插件，体积较重 |

## 3. 只研究，不默认复制

| 项目 | 原因 |
|---|---|
| Readest | 架构和阅读体验很有参考价值，但主体是 AGPL-3.0 |
| Koodo Reader | 多格式和书架值得研究，但主体是 AGPL-3.0 |
| Calibre | 格式能力强但 GPL-3.0 且体量重，不作为闭源首版内嵌底座 |

AGPL/GPL 代码不得因为“开源”就直接复制到闭源商业项目。任何例外都必须先明确分发方式和开源义务。

## 4. 适配器封装规则

第三方依赖必须：

1. 固定版本或 commit。
2. 记录项目 URL、版本、许可证和版权声明。
3. 放在独立适配器中。
4. 有最小测试样本。
5. 允许未来替换。
6. 不把第三方内部对象写进数据库公共 schema。

建议建立：

```text
THIRD_PARTY_NOTICES.md
licenses/
docs/dependencies/<name>.md
```

## 5. 安全注意

### EPUB

- 电子书可能包含 HTML、CSS 和脚本。
- 禁止执行书中脚本。
- 使用 CSP 和 sandbox。
- 外链交给系统浏览器。
- 禁止任意本地文件读取。

### PDF

- 更新 PDF.js 安全版本。
- 限制超大文件和恶意对象。
- 解析放 Worker。

### DOCX

- 不信任嵌入链接和外部关系。
- 清理生成 HTML。

### URL

- 防止 SSRF。
- 限制协议、重定向、响应大小和内容类型。
- 桌面端 HTTP 适配器不允许访问本地网段，除非用户显式授权。

## 可重复执行

浏览器安装已有 Playwright 时，在预览服务器运行后执行：

```powershell
node tools/test-data-flows.cjs http://127.0.0.1:4173
```

可通过 `NODE_PATH` 指向已有 Playwright，默认复用系统 Edge，无新项目依赖。

桌面验证配置应保存在 `output/verification`，不要放在会被测试脚本清理的 `.build`：

```json
{
  "productName": "弹阅验证",
  "identifier": "com.generalconsulting.tanyue.validation",
  "version": "0.2.3",
  "app": { "windows": [{ "label": "main", "title": "弹阅验证", "width": 1320, "height": 850 }] }
}
```

```powershell
$env:WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS='--remote-debugging-port=9223'
npm run tauri:dev -- --config D:/tanyue/output/verification/desktop-validation.json
# 在另一个终端：
node tools/test-desktop-flows.cjs --update
```

脚本先验证数据库路径属于 `.validation` 才操作。调试端口仅用于隔离开发验证，正常安装版不启用。

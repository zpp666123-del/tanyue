# 弹阅命名与品牌说明

原名“隙读”存在明显不良谐音，已经永久弃用。

当前产品名称确定为：**弹阅**。

## 名称含义

“弹阅”由“弹出”与“阅读”组合而来：

- 内容像桌面弹窗一样，在合适的时间主动出现。
- 用户可以读完、继续、延后，也可以安静关闭。
- 名称直接体现产品最有辨识度的使用方式，而不是把它误解为传统阅读器。

品牌主张：

> **少而精地读，深而静地思。**

辅助文案：

> 阅读，让思考更有回响。

## 品牌视觉

- 主色：温暖、克制的陶土橙。
- 背景：米白、浅灰、透明玻璃层。
- 标志：两页打开的书，外形简洁，适合桌面悬浮图标。
- 气质：安静、轻量、现代，不使用强打卡、竞争或焦虑文案。

## 上线前仍需完成

名称已用于当前工程，但正式商业发布前仍应完成：

- 中国商标近似检索。
- 主要域名和社交账号检查。
- Microsoft Store、Mac App Store 和主要应用市场重名检查。
- GitHub、Gitee、软件著作权和公司内部产品名检查。
- 普通话及主要方言谐音检查。

## 工程中的品牌入口

- `src/utils.ts`：`BRAND` 配置。
- `src/index.html`：网页标题与描述。
- `src-tauri/tauri.conf.json`：安装包产品名与标识符。
- `src-tauri/Cargo.toml`：Rust 包名。
- `public/icons/` 与 `src-tauri/icons/`：图标资产。
- `README.md`、文档和导出文件名。
